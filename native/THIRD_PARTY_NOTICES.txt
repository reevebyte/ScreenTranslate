ScreenTranslate Native Third-Party Notices
==========================================

The native ScreenTranslate executable is built with the Microsoft Visual C++
toolchain and Windows SDK. It uses Win32, Windows Runtime, Windows OCR, and
C++/WinRT system interfaces. No Qt, Python, .NET, Tauri, NuGet package, OCR
model, or third-party runtime DLL is bundled in the default native release.

Optional RapidOCR plugin
------------------------

The native executable exposes a plugin ABI and a hardened loader for an
optional ScreenTranslate.RapidOcr.dll. The default release does not contain a
RapidOCR implementation, its native dependencies, or model files. Anyone who
distributes such a plugin must provide the notices and license texts required
by the plugin, inference runtime, and model sources alongside it.

Network service notice
----------------------

The key-free translation providers and Youdao cloud OCR communicate with
public web pages or first-party client endpoints. They are not official
developer APIs. They can be rate-limited, changed, or disabled without notice,
and their use may be subject to each provider's terms of service.
