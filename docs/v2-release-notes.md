### macOS 首次安装与更新权限提示
由于本项目为开源自编译/分发、未购买苹果商业开发者证书，更新二进制后若出现录屏无法捕捉：
- 可在终端执行一步重置命令即可直接弹出新授权询问：`tccutil reset ScreenCapture io.github.reevebyte.screentranslate.v2`
