# ScreenTranslate 2.0.11

- 彻底解决侧边栏收起/展开时的剧烈震动与位移：导航项固定左对齐锚点与图标边距，移除容器居中造成的瞬时横向位移；优化高亮指示器在尺寸动画时直接同步，消除 Spring 弹性物理共振。
- 优化加宽窗口（~680px）下的设置页与关于页布局：扩大关于页卡片宽度至 520px，关于内容在窗口纵向自动居中对齐，调整应用标识与资源列表呼吸间距，消除底部大块留白与比例失衡。
- 侧边栏折叠时导航图标与高亮指示器严格居中对齐，消除偏左视觉偏移；收起/展开切换时图标水平轴线保持平稳。
- 侧边栏底部折叠按钮尺寸与居中对齐统一为 40px，匹配上部导航项与悬浮/焦点圆环。
- 标题栏更新按钮引入 GDI 内存双缓冲与 `WM_SETTEXT` 拦截，消除下载进度流式更新时的背景频闪。
- 标题栏“重启更新”按钮点击直接启动安装器并重启应用，消除无响应问题。
- 升级 GitHub Actions macOS runner 镜像至 macos-15，确保多平台发布自动化稳定运行。
