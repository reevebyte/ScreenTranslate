- 升级截图结果页与悬浮工具条操作：
  - 主窗口「截图结果」页点击「重新翻译（刷新）」或「打开图片」改为本页原地完成，不再意外弹出悬浮截图窗与工具条；
  - 移除主窗口工具栏中冗余的「校对文字」按钮，直接点击译图中的文字块即可校对修改；
  - 将「复制译文」升级为「复制译图」（按原图分辨率合成最新翻译/校对结果写入剪贴板），「提取文字」升级为「复制文字」下拉菜单（上下排布「原文」与「译文」，原生 Wayland 极矮单行截图下自动紧凑排布防裁切），主窗口额外新增「另存为」支持保存 PNG / JPEG / WebP，且复制与保存成功后按钮图标统一变为 `✔` 反馈。
- 优化 Linux 悬浮工具条定位与拖动体验：为独立 `result-tools` 窗口启用 `Utility` 窗口类型并绕过 GTK3 位置缓存直接同步 `GDK` 窗口坐标，解决 GNOME Mutter 下工具条紧贴截图底部间距偏大的问题；同时为原生 Wayland 内嵌模式增加停靠边界夹紧，杜绝拖动时工具条被窗口边缘裁切。
- 降低 Linux 端内存开销：所有 Linux WebView 切换至 WebKitGTK `DocumentViewer` 缓存模式并关闭未使用的 WebGL / 媒体 / 页面缓存子系统，默认限制 `MALLOC_ARENA_MAX=2`，并在回收隐藏窗口与释放旧截图缓存后主动调用 `malloc_trim(0)` 归还空闲堆页。
