# ScreenTranslate 2.0.17

- 彻底解决从上边框和左边框伸缩窗口时右边缘与下边缘组件抽搐、闪烁及残影问题：借鉴并对齐 FlClash / Chromium 桌面端标准窗口底层管理方案，为主窗口挂接持久 Win32 消息过程子类化（Subclass），拦截 WM_WINDOWPOSCHANGING 并在窗口尺寸改变时显式标记 SWP_NOCOPYBITS，完全阻断 Windows 系统默认 GDI BitBlt 位图平移回拷，将渲染主导权与双缓冲交换全权交由 DirectComposition / WebView2，彻底消除边缘控件在缩放过程中的位移帧与重绘抽搐。
- 侧边栏底栏与“展开侧栏”按钮布局流优化：导航轨底栏改造为原生 Flexbox 自动推底流（margin-top: auto），移除绝对定位与容器布局强制隔离，杜绝窗口高度伸缩时亚像素计算抖动。
- 彻底根除有更新时切换主题标题栏“下载更新/重启更新”按钮的频闪问题：重构原生 Caption 按钮的 sync 与 update 重绘调度管线，去除 sync 末尾无条件无效化调用，对位置未变、颜色未变、文案状态未变的刷新调用做完全短路过滤，保证主题切换时仅发生单次干净的颜色过渡重绘。
- 截图选择提示条胶囊全面自适应浅色与深色主题：在原生创建选区窗口时同步注入当前激活主题参数，并在根节点脚本首帧即时应用，确保浅色主题下呈现明亮透澈的白底毛玻璃胶囊，深色主题下呈现沉稳夜色胶囊，色彩、边框与 Esc 快捷键药丸质感完全自适应。
- 统一 FlClash 极简设计风格并清理冗杂代码：全局保持统一的圆角卡片、居中轻量提示、舒适行高与高对比度图标，移除废弃样式与冗余重绘逻辑。
