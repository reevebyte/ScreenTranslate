# ScreenTranslate 2.0.19

- 彻底根治主窗口拖动缩放右侧残影与撕裂：对齐 ModelBench 原生轻量架构，完全移除在 Win32 消息循环中对主窗口强行注入的背景色绘制覆盖与 DWM 动画禁用（DWMWA_TRANSITIONS_FORCEDISABLED），恢复 Windows DWM 原生硬件合成与平滑缩放同步机制。
- 消除快速缩放窗口时的黑边：将 Win32 原生窗口背景刷及 WebView2 默认底色与当前主题色实时同步，消除跨进程排版重绘期间的对比度黑条。
- 完善 OpenCode Go 兼容连接支持：针对 OpenCode 网关自动注入会话请求头并规范化服务地址，优化接口报错详情回传，并在服务预设中新增 OpenCode Go 选项。
- 消除切换至截图结果时的画面闪烁：将画板底色规范为透明，移除导航切换时的全量 DOM 强制重构，并在主窗口中平滑同步图文就绪状态，实现即切即显。
- 优化前端容器与根视口防溢出机制：给 html 根元素赋予主题背景色并在浮层窗口保持透明，严格限制主视图与工作区的 100% 宽高与 overflow 裁剪，防止视图在剧烈拉伸时产生重排滞后与边缘拖影。
- 优化标题栏更新按钮生命周期与测试套件：消除隐藏状态下重复调用 ShowWindow 的系统消息干扰，全面通过全部原生测试与自动化校验。
