# ScreenTranslate 2.0.38

- Linux Wayland 截图体验大幅改进：按快捷键后静默截取整屏，直接在应用内框选，不再每次弹出系统截图界面；首次截图时系统可能询问一次权限，选择允许并记住即可。
- Linux Wayland 下译文结果窗可贴回原文位置，并能自由拖动、用方向键微调；窗口默认通过 XWayland 运行，如需原生 Wayland 窗口可设置环境变量 SCREENTRANSLATE_NATIVE_WAYLAND=1。
- Wayland 截图不再在“图片”文件夹中留下临时截图，也不会误用相册里的旧截图。
- 快速文字翻译移除“原译对照”弹窗，译文区只保留复制按钮，界面更简洁。
- 服务中心的模型下拉列表与输入框等宽，并随窗口大小实时调整。
