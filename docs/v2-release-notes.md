# ScreenTranslate 2.0.16

- 彻底消除拉伸窗口上边沿时“展开侧栏”按钮乱动与残影：移除独立 GPU 合成层（translateZ）导致的图层帧不同步重影，将底栏改造为绝对像素底部物理锚定，结合容器布局隔离（contain: layout）消除弹性布局延迟。
- 全面清理冗余代码与废弃样式：清除设置页卡片展开后遗留的无用折叠样式（.settings-more）、旧版底栏遗留规则（.workspace-footer、.footer-actions）、未使用的类选择器与组件无用图标导入，大幅提升代码整洁度。
- 维持极简统一的 FlClash 视觉风格与交互体验：全套自适应浅色与深色胶囊提示、居中轻量浮动通知、大圆角卡片、50px 舒适行高与稳定对齐。
