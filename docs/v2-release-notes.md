- 安全与内存安全加固：
  - 修复 Windows 标题栏更新按钮重入释放与旧配置 DPAPI 解密边界，以及 macOS 跨线程窗口指针与 ScreenCaptureKit 超时竞态；
  - 固定 Linux `.deb` 提权更新的系统二进制绝对路径、及时清零密码缓冲并防止并发重复安装；
  - 修复密钥删除失败静默吞错与切换「仅本次会话」未清理旧钥匙串项的问题，并脱敏远端错误提示中的令牌片段；
  - 收紧生产包 CSP（移除 `script-src` 的 `'unsafe-inline'`），仅在调试模式放行本机开发源导航与 `frame://` 跨域访问，配置目录不可用时改用私有临时目录。
- 稳定性与并发竞态修复：
  - 修复取消重截后悬浮结果窗无法再次打开、后台窗口回收误伤待显示结果窗导致选区卡死、延迟 `result_presented` 误杀新截图、以及启动瞬间连按快捷键触发单实例 Panic 的问题；
  - 将截图预览编码移出缓存互斥锁并支持派生渲染层按需淘汰旧缓存，修复局部校对与打开图片边界状态同步问题。
- 交互细节优化：
  - 修复选区出错时「返回」按钮无法点击、Windows 取消安装向导后更新弹窗锁死、修改设置重置自动检查更新计时器、快捷键冲突回滚竞态，以及长按/连点快捷键和保存按钮等边界体验问题。
