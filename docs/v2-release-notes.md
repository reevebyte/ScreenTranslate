# ScreenTranslate 2.0.37

- 新增“快速查找”全局快捷键（默认 Ctrl+Alt+K），在任意程序中都能呼出主窗口搜索；已把该组合键用于其他功能的用户保持原设置不变。
- 统一提醒样式：主窗口的警告、错误和成功提示集中显示在右上角并自动消失，保存失败会写明原因并可重试；快捷键冲突会指出具体按键并自动恢复原快捷键。
- 快速文字翻译窗口重新布局：翻译按钮移到顶部，复制与原译对照放到译文右上角，输入与译文区域更宽敞。
- 校对文字窗口改为原文、译文双卡片，修改与翻译状态显示在卡片标题栏，重译时窗口不再变形。
- 修复退出时正在输入的设置可能丢失、配置文件损坏后会被默认值覆盖、DeepL 中文源语言报错、单个空译文导致整批失败等问题。
- 加强 Linux 更新安装与发布签名安全；设置、服务中心、截图结果页等多处外观细节优化。
