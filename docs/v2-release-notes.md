# ScreenTranslate 2.0.14

- 截图提示条升级为 FlClash 悬浮胶囊风格：采用圆润药丸胶囊轮廓与深色毛玻璃质感，内嵌精致细分割线与药丸按键徽标，视觉轻盈现代。
- 消除垂直调整窗口时侧栏折叠按钮抖动：图标采用偶数像素居中对齐，底栏与切换按钮增加抗挤压锁定，消除亚像素渲染引起的轻微晃动。
- 消除水平拉宽窗口时组件突兀下坠：优化窄屏媒体查询断点，确保主窗口在 680px 默认尺寸及向外拉伸时内边距与行高完全平稳，避免跳变下坠。
- 锁定默认窗口即为最小尺寸限制（680×520）：默认尺寸与最小尺寸严格一致，不支持向上缩窄，仅支持向外自由拉大。
- 展开设置分组卡片：常规设置中的“更多设置”与外观设置中的“强调色”直接以卡片分组展开显示，充分利用窗口空间。
- 优化设置行高与视觉间距：将设置行最小高度从 42px 增至 50px，图标槽放大至 36px，下拉选择框增至 34px，消除扁挤感。
- 增加平滑切换过渡动效：主设置面板与服务选项卡切换新增温和淡入动效，侧边栏与标签项点击提供微交互触感反馈。
