# ScreenTranslate 2.0.39

- 修复 macOS Retina 屏幕截图缩放与繁体中文（zh-Hant）OCR 识别问题，并完善 Linux 繁体中文（zh-Hant-TW / zh-Hant-HK）系统 OCR 语言映射。
- 修复选区重译与快速翻译在取消、空输入或窗口异常时可能残留运行中状态的问题；增强 Windows OCR 与图片渲染对空图像的安全防护，将图像放大与云端 OCR 编码移至后台线程避免阻塞界面。
- 修复清除已显示密钥时输入框可能回弹为旧值、快捷键冲突提示点击恢复无法跳转到快捷键设置，以及检查或下载更新期间缺少状态提示与防重入保护的问题；更新界面标题文字随语言切换即时重绘。
- 修复旧版 Anthropic 自定义接口地址末尾可能重复拼接 `/v1`、部分翻译错误详情过长，以及应用退出时未及时恢复系统选区动画与完成待保存编辑的问题；清理未使用的依赖、图标与组件资源。
