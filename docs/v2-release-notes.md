# ScreenTranslate 2.0.6

- 托盘菜单改为底部版本状态行，无更新时置灰显示当前版本，有新版时高亮可点击直接更新，并同步中英文界面语言。
- 自动更新新增 Windows 系统代理与环境变量代理识别，支持代理中断自动回退直连，修复 GitHub Releases 跳转下载失败问题。
- 手动检查更新无新版时改为窗口居中弹窗提示“✓ 已是最新版本”，移除按钮下方常驻文字。
- 主窗口默认与最小尺寸固定为 600×400，侧边栏默认收起为图标模式，精简关于、设置、快捷操作页间距以消除上下滚动条。
- 全面统一 FlClash 柔和视觉风格：原生标题栏与主界面同色融合，标题栏更新按钮采用抗锯齿圆角胶囊并同步应用主题，设置、服务中心、文字识别与命令面板统一圆底图标与圆角分组卡片。
- 全局禁用右键默认浏览器菜单。
