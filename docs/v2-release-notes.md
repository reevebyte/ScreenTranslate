# ScreenTranslate 2.0.35

- 大幅降低 Windows 托盘截图启动延迟：普通托盘入口不再固定等待，多显示器改为并发抓取，并复用轻量选区窗口快速显示预览。
- 修复 Linux Wayland 下截图结果窗口再次拖动需要额外点击一次的问题，连续拖动现在可直接开始。
- 加强翻译与 OCR 网络响应保护：保留正常响应上限，并将错误详情限制为小尺寸，避免异常服务占用过多内存。
- 更新存在安全风险的 JavaScript 与 ZIP 依赖，同时保持现有安装包和自动更新流程兼容。
- 提升 Linux 构建环境稳定性：系统依赖安装增加超时、重试和精简包选项，避免软件源波动导致 CI 长时间卡住。
