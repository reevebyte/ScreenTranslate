# 内存与体积

本机 Windows / WebView2 正式程序冷启动，主窗口空闲，3、8、15 秒采样；统计主程序和全部子进程，保留系统正常工作集，不作强制修剪。以下为 15 秒样本，单次短测不代表所有硬件和场景的长期均值。

| 指标 | 2.0.1 | 2.0.2 |
| --- | ---: | ---: |
| 整组私有工作集 MiB | 115.4 | 113.1 |
| 整组私有提交 MiB | 220.0 | 220.2 |
| EXE MiB | 13.07 | 10.16 |
| NSIS MiB | 3.73 | 3.19 |

私有工作集是实际驻留物理内存；私有提交包含未必驻留的内存。各进程的共享工作集相加会重复计算共享页，因此不能用它冒充独占占用。提交量并未随包体积同步下降，保留原始结果，不将短时波动全部归因于改动。

截图优化针对持续使用：新截图呈现后释放旧缓存，晚到回调保留较新的未呈现截图；译图仅保留 PNG，不再多存一份 RGBA。例如 3840×2160 译图少保留 31.64 MiB 的原始像素，不含 PNG 压缩数据。20 次替换回归验证当前缓存只保留原图和其译图；没有压缩原图或删除仍需使用的数据。

标题栏按钮使用原生 HWND 和 GDI，不增加 WebView；重启确认框按需加载。软件继续使用系统 WebView2，安装包不附带整套浏览器运行时。体积优化参考 [Tauri 官方说明](https://v2.tauri.app/concept/size/)。

本机采样细节和进程记录位于 build/release-2.0.2/memory-*.json；没有上传到远端。本轮未做所有 DPI、GPU、长时间翻译负载的性能对比。
