# 开发指南

## 环境

- Node.js 22、pnpm 11.7.0、Rust 1.95.0。
- Windows：MSVC Build Tools 的桌面 C++ 工具链、Windows SDK、WebView2。
- macOS 14+：Xcode Command Line Tools，系统 ScreenCaptureKit / Vision。
- Ubuntu 24.04：WebKitGTK 4.1、GTK 3、AppIndicator、X11 / PipeWire 开发库；本地 OCR 使用 Tesseract 与语言包。CI 的依赖安装清单见 .github/workflows/v2-ci.yml。

运行 `pnpm install --frozen-lockfile` 后用 `pnpm desktop` 启动。`pnpm dev` 只预览 Svelte 界面。

## 结构与边界

Rust core 管理会话、请求取消、翻译和布局；platform 管理截图、OCR、凭据与旧版 DPAPI 导入。`crates/platform/native/macos.m` 是当前 macOS 实现的一部分，必须保留。旧 Windows C++ 工程已退出当前源码目录，Git 历史可恢复它。

Svelte 使用语义 token、Bits UI 与 shadcn-svelte 组件，品牌资源本地打包。界面语言在 WebView 本机存储中记忆，通过应用事件同步；不改变原文、译文、翻译目标语言或 API 配置。

配置 JSON 不保存 API Key，密钥进入系统凭据库；不可用时使用会话内存。测试程序使用独立标识、临时配置、内存凭据和 localhost 服务。

## 验证

```sh
cargo fmt --all --check
cargo clippy --workspace --all-targets --locked -- -D warnings
cargo test --workspace --locked
pnpm types:check
pnpm check
pnpm test
pnpm build
node scripts/measure-v2.mjs
node --test scripts/clean-v2-builds.test.mjs
pnpm --filter @screentranslate/desktop test:e2e
```

原生 E2E 会先构建专用驱动版本，再独立启动四组测试，避免驱动、窗口与本机服务地址串组。Windows 物理边缘采样需要 Python，仅记录合成图片的边缘位置。验证范围见 [记录](validation.md)。

## 正式构建

`pnpm --filter @screentranslate/desktop tauri build --bundles nsis`；跨平台也可使用 scripts/build-v2.ps1 或 build-v2.sh。普通构建不含测试驱动。所有版本字段使用标准 SemVer，例如 2.0.0、2.0.1。

源码发布时提交 Cargo.lock、pnpm-lock.yaml、许可和文档；.gitignore 排除 target、node_modules、build、dist、私钥、环境文件与诊断日志。不要将本机归档或构建缓存提交到 GitHub。

指定 `--target` 时，产物位于 `target/<target>/release`，Windows 版本化 EXE 别名也保存在该目录；未指定目标时沿用 `target/release`。

应用名称为 ScreenTranslate，版本号单独递增。许可证与第三方说明安装到 licenses/ 子目录。图标源为 apps/desktop/src-tauri/icons/app-icon.svg，使用 Tauri icon 生成各平台资源；不要重新嵌入位图代替矢量路径。

首次使用标志保存在系统配置目录的 config.json。全新配置会自动弹出指南；已完成用户升级或重装后保留该状态。wdio.first-run.conf.mjs 使用独立临时配置验证自动引导，不清除用户真实配置。
